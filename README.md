=====================================================
QUIZ INTERATIVO - PRÁTICAS DE ENFERMAGEM
=====================================================

1. COMO ABRIR O PROJETO NO IPHONE LOCALMENTE:
-----------------------------------------------------
- Abra a aplicação "Ficheiros" do iOS no seu iPhone.
- Navegue até à pasta "quiz-enfermagem".
- Toque diretamente no ficheiro "index.html".
- O quiz abrirá no Safari ou no navegador interno do iOS para poder jogar.

2. COMO ENVIAR OS FICHEIROS PARA O GITHUB:
-----------------------------------------------------
- Aceda ao site https://github.com no Safari (faça login ou crie uma conta gratuita).
- Clique no ícone "+" no canto superior direito e selecione "New repository".
- Escolha um nome para o repositório (ex: "quiz-enfermagem").
- Mantenha a visibilidade como "Public".
- Clique no botão "Create repository".
- Na página que se abre, toque em "uploading an existing file" ou "Add file" > "Upload files".
- Selecione e envie os ficheiros (index.html, style.css, script.js e README.txt) diretamente para a raiz do repositório (fora de subpastas).
- Toque no botão verde "Commit changes".

3. COMO ATIVAR O GITHUB PAGES:
-----------------------------------------------------
- No seu repositório no GitHub, clique na aba "Settings" (Definições) no topo da página.
- No menu lateral esquerdo, selecione "Pages".
- Em "Build and deployment" -> "Branch", altere de "None" para "main" (ou "master").
- Garanta que a pasta selecionada é "/ (root)".
- Clique em "Save".

4. COMO OBTER O LINK PÚBLICO:
-----------------------------------------------------
- Aguarde cerca de 1 a 2 minutos após guardar as definições.
- Atualize a página de definições do "Pages".
- Aparecerá uma caixa verde com o endereço público (exemplo: https://seu-usuario.github.io/quiz-enfermagem/).
- Partilhe esse link com quem quiser para aceder ao quiz a partir de qualquer iPhone, Android ou computador!
